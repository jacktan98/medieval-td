# Start page

The artwork for the start page: the first screen a player sees, before the world
map, with the game's logo and the Start button (like Kingdom Rush 1's).

Nothing here is in the game yet. Upload the pictures to this folder, and the start
page is then built from them.

## What to draw

Drawn in layers rather than as one picture, so the page can move a little (flags
waving, crows circling, the logo dropping in) and so one part can be redrawn
without the rest:

| Suggested name | What it is |
|------|------------|
| Start_Background.svg | the scene behind everything, the full screen |
| Start_Logo.png | the logo on its own, transparent around it: the name of the game and its badge |
| Start_Characters.png | the defenders and enemies standing in front of the scene, transparent around them (or one file each) |

Other names are fine; say what each one is when you upload it, and this list is
updated to match.

## Sizes

- **1920 × 1080**, the same as the stage maps, for the background and any layer
  meant to be laid over the whole screen.
- **The logo on its own canvas**, about 900 × 600, so it can be reused for the
  loading screen and the ending.
- **Leave room for the buttons**: the Start button goes under the logo in the
  middle, the music and sound buttons in a corner, and "Created by Jack Tan" along
  the bottom. Nothing important under those.

The drafts to draw over are the three title page mockups (A Castle Gate, B Old Map,
C Dark Hollow).
