# The itch.io build's extra files

Copied into the zip by `tools/itch.mjs`; nothing in the game loads them.

| File | What it is |
|------|------------|
| `OFL.txt` | Lobster's licence, which the SIL Open Font License asks to travel with the font; it goes in as `assets/fonts/OFL.txt` |
| `CREDITS.txt` | who made the game and what it uses, at the top of the zip |
